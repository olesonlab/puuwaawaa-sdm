# Structured Decision Making at Puʻuwaʻawaʻa Forest Reserve

Code and data for:

> Oleson, K.L.L., Trauernicht, C., Lonsdorf, E., and Parsons, E.W.
> **"Structured Decision Making reveals asymmetric tradeoffs between conservation
> and community objectives at Puʻuwaʻawaʻa Forest Reserve, Hawaiʻi"**
> *Conservation Science and Practice* (submitted)

A companion paper on normalization methods is available at:
[github.com/olesonlab/puuwaawaa-normalization](https://github.com/olesonlab/puuwaawaa-normalization)

---

## Overview

This repository contains the integer-programming optimizer and figure-generation
scripts used to evaluate 11 management alternatives across 22 paddocks at
Puʻuwaʻawaʻa Forest Reserve under seven stakeholder weighting scenarios and five
budget levels ($5M–$60M).

**Key findings:**
- Conservation outcomes are budget-constrained; community objectives are not
- $10M is a practical inflection point: below it, all scenarios converge; above it, genuine tradeoffs emerge
- Rancher and conservation interests align under Alternative 1 (fence + fuelbreaks)
- The Rancher-Conservation scenario is 3.3× more efficient than Community Priority
  in terms of T&E plants lost per rancher point gained

## Setup

```bash
# Clone
git clone https://github.com/olesonlab/puuwaawaa-sdm.git
cd puuwaawaa-sdm

# Create environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

---

## Usage

### 1. Run the optimizer

```bash
python src/pww_sdm_optimizer.py data/pww_sdm_input_data.xlsx results/
```

This produces three CSV files in `results/`:
- `sdm_results_summary.csv` — one row per scenario × budget
- `sdm_results_paddock_detail.csv` — one row per scenario × budget × paddock
- `sdm_scenario_definitions.csv` — scenario weight definitions

### 2. Generate figures

```bash
python src/figures.py --results_dir ./results --output_dir ./figures
```

Produces Figures 3–7 from the paper.

## Data

The input data file (`pww_sdm_input_data.xlsx`) contains expert-elicited
consequence scores, paddock-level spatial data, fire probability estimates,
and cost estimates developed during a 2018 rapid-prototyping workshop with
DOFAW managers.

See `data/README_data.md` for full metadata and access instructions.

The data are archived at: **https://doi.org/10.5281/zenodo.20369405**
